# Troubleshooting

For the native XeLL HTTP/authentication build, start with [NATIVE_HTTP.md](NATIVE_HTTP.md). DHCP must show a verified ACK lease; a nonzero IP alone is insufficient. Use the server's LAN IPv4 and port, not the Xbox's own address. A PHY watchdog timeout requires a reboot before retry; an HTTP timeout/cancel can be retried from the UI. The user-confirmed baseline graphics/controller/audio/Ethernet functionality remains in this build.

- **No XEX / Aurora cannot launch the file:** the native artifact is a bare-metal diagnostic ELF for an existing XeLL setup. There is no completed dashboard client. Read PLATFORM.md.
- **Cloud cannot reach a private address:** `192.168.68.202` is a LAN address. A cloud task needs an actual route, such as a platform-managed VPN, as well as any applicable network allowlist. Changing the allowlist alone does not create that route. Do not install a separate VPN client as a workaround.
- **Public hostname returns a proxy 403:** review the domain in environment network settings and save/apply the configuration. The observed cloud CONNECT rejection does not prove that the Jellyfin server itself rejects authentication. The repository does not hardcode or modify your server.
- **HTTPS certificate error:** check hostname, certificate chain and validity, clock and the system CA bundle. Install the issuing CA through your system's supported trust configuration if appropriate. Do not use `-k`, disable peer checks, or change the client to accept arbitrary certificates. The TLS rejection integration test intentionally uses an untrusted certificate.
- **Non-Jellyfin response:** use the actual server base URL, including a reverse proxy base path. `/System/Info/Public` must return Jellyfin JSON including `Version`.
- **Authentication error:** use the server account's real username and password. Token expiry/401 returns to login; 403 may instead indicate account permissions or reverse proxy policy. A local logout clears the stored session but does not revoke every server session.
- **Configuration permissions error:** the desktop settings file must be a regular file owned by the current user with mode 0600. Set `XENONFIN_SETTINGS` to a writable path outside the checkout if needed. It contains a private bearer token when remember-login is enabled.
- **Missing font:** install DejaVu Sans or set `XENONFIN_FONT` to an existing TrueType font. No font is silently downloaded.
- **SDL audio/video unavailable:** on an actual desktop verify audio drivers, window/display access, controller permissions and SDL mappings. Use `--headless --seconds 1` only for cloud smoke tests; dummy drivers produce no visible or audible output.
- **Unsupported playback / no progressive transcode URL:** ensure Jellyfin permits transcoding for the account, has a functioning FFmpeg installation and can supply HTTP MPEG-TS H.264/AAC (or MP3 audio). HLS-only and cross-origin media servers are refused by this implementation. Verify codecs and containers from PlaybackInfo; don't guess another URL.
- **Direct Play seek fails:** the static endpoint/proxy must preserve byte-range requests and content length. Transcoded seeks use a new negotiation/session. A proxy returning 200 to a nonzero byte range is rejected.
- **Stream interruption:** cancel or stop, restore the connection and retry playback; the UI remains on details and the last reported position is retained on the server when reporting succeeded. Transparent midstream reconnection is not implemented. Idempotent API GET/HEAD requests retry a transient connection failure once; password submissions and playback reports are not blindly retried.
- **Gap between songs / very large album:** queue transitions reopen the decoder/output path; gapless playback is not implemented. The queue cap is 200 tracks and an oversized album raises an explicit error. Use paged browsing and smaller queues.
- **Missing thumbnails:** artwork failures are optional and retain the title/type card. Confirm image access, response size and supported JPEG/PNG encoding. Encoded images are capped at 2 MiB; decoded source pixels at 2048×2048; resized textures at 240×360.
- **Dependency pin unavailable:** do not remove TLS/signature/checksum verification. Use an authenticated distribution snapshot or intentionally update pins and rerun the tests. The cloud script depends on the prepared Debian 13 runtime; it is not a universal package installer.

Normal errors print short descriptions/statuses. Do not attach settings files, Authorization headers, password bodies, signed media URLs or raw server logs containing credentials to issues. Provide server/client versions, sanitized error descriptions, source revision and codec metadata instead.
